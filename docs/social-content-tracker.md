## Draft queue

### LinkedIn draft: supplier directory / planner

Most corporate gifting problems do not start with the bottle.

They start with unclear questions:

- Is wine appropriate for this recipient?
- Is this for one senior contact or a whole team?
- Should this be a bottle, hamper, Champagne, alcohol-free option or something else?
- Can the supplier handle multiple addresses, gift notes, VAT invoices and substitutions?

I’ve been building ClientCellar to help UK business buyers think through those decisions before they start browsing supplier catalogues.

There is now a free gift planner and a supplier directory covering practical routes for corporate wine gifts, client hampers and event drinks.

It does not sell wine directly, and it does not pretend every supplier is a partner. The aim is simpler: help buyers create a better brief and ask better supplier questions.

Useful starting point:
https://clientcellar.co.uk/supplier-directory

### Facebook draft: practical gift planning

Choosing a client gift can get awkward quickly.

Wine might be right, but sometimes a hamper, Champagne, mixed case or alcohol-free option is safer. The harder part is usually knowing what kind of supplier to approach and what questions to ask before ordering.

ClientCellar is a free UK planning site for corporate wine gifts, client hampers and event drinks. Use it to shape a quick brief by recipient, budget and occasion before contacting suppliers.

Start with the free gift planner:
https://clientcellar.co.uk/gift-planner

Or browse supplier routes:
https://clientcellar.co.uk/supplier-directory
